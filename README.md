Sketch Tutor 🎨

An AI-powered web application designed to help users learn drawing through step-by-step guides generated from uploaded reference images.

About

Sketch Tutor aims to make learning drawing easier by helping users understand how to approach a drawing using a reference image.

Features

- Upload a reference image.
- Generate a step-by-step drawing guide using AI.

Getting Started

1. Open the Sketch Tutor website.
2. Upload a reference image.
3. Generate a drawing guide.
4. Follow the instructions to practice drawing.
